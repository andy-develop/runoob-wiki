C 语言环境搭建

在开始学习数据结构与算法之前，需要先搭建一个可以顺利编译和运行 C 程序的开发环境。

也可以参考我们的 C 语言教程章节安装设置：https://www.runoob.com/cprogramming/c-environment-setup.html

编译器安装

本教程推荐使用 GCC（GNU Compiler Collection），它是跨平台、开源且广泛应用于生产环境的 C 语言编译器。

Windows 系统

在 Windows 上，推荐通过 MinGW-w64 或 MSYS2 来获得 GCC 编译环境。

安装步骤：

  1. 访问 MinGW-w64 官网 下载安装程序
  2. 运行安装程序，选择架构为 x86_64，线程模型选 posix
  3. 安装完成后，将 MinGW-w64 的 bin 目录（如 C:\mingw64\bin）添加到系统环境变量 PATH 中
  4. 打开命令提示符（cmd），输入 gcc --version 验证安装是否成功
C:\Users\runoob&gt; gcc --version
gcc (MinGW-W64 x86_64-posix-seh) 13.2.0
Copyright (C) 2023 Free Software Foundation, Inc.

macOS 系统

在 macOS 上，安装 Xcode 命令行工具即可获得 GCC（实际是 Clang 的封装，兼容 GCC 用法）。

打开终端，执行以下命令：

$ xcode-select --install

系统会弹出安装提示，点击"安装"并等待完成。

安装完成后，验证编译器是否可用：

$ gcc --version
Apple clang version 16.0.0 (clang-1600.0.26.4)
Target: arm64-apple-darwin25.5.0
Thread model: posix

Linux 系统

大多数 Linux 发行版都可以通过包管理器一键安装 GCC。

Ubuntu/Debian 系统：

$ sudo apt update
$ sudo apt install gcc build-essential

Fedora/CentOS 系统：

$ sudo dnf install gcc gcc-c++

验证安装：

$ gcc --version
gcc (Ubuntu 13.2.0-4ubuntu3) 13.2.0

IDE 推荐

以下是几款适合初学者的 C 语言集成开发环境。

IDE平台特点适合人群
VS Code全平台轻量级、插件生态丰富、配置灵活，搭配 C/C++ 插件使用喜欢自定义配置的学习者
Code::Blocks全平台专为 C/C++ 设计、开箱即用、自带 MinGW（Windows 版）初学者、不想折腾配置

本教程的代码示例不依赖特定 IDE，使用任何一款都可以正常编译运行。

如果你不想在本地安装任何工具，也可以使用在线编译器（如 Compiler Explorer、OnlineGDB）快速验证代码。

对于初学者，本教程推荐 VS Code + MinGW-w64（Windows）或 VS Code + Xcode 命令行工具（macOS）的组合，轻量且功能完备。

第一个 C 程序

搭建好环境后，立即编写并运行经典的 "Hello, World!" 程序，确认一切配置正确。

创建一个新文件，命名为 hello.c，输入以下代码：

实例

#include <stdio.h>  /* 标准输入输出头文件，提供 printf 函数 */

int main() {
    /* printf：向控制台输出字符串的函数
       \n：换行符，让光标移动到下一行 */
    printf("Hello, World! Welcome to RUNOOB DSA Tutorial!\n");
    return 0;  /* 返回 0 表示程序正常结束 */
}

代码结构说明（从上到下）：

代码部分说明
#include <stdio.h>预处理指令，引入标准输入输出库，使我们可以使用 printf 函数
int main()程序的入口函数，每个 C 程序都从 main 函数开始执行
printf(...)格式化输出函数，将括号中的字符串打印到屏幕上
return 0;向操作系统返回退出码，0 表示程序正常结束

保存文件后，在终端中使用以下命令编译并运行：

# 编译：将 hello.c 编译为可执行文件 hello
$ gcc hello.c -o hello

# 运行，Windows 下为 hello.exe
$ ./hello
Hello, World! Welcome to RUNOOB DSA Tutorial!

如果终端中正确输出了上述文字，说明你的 C 语言开发环境已经配置成功。

编译命令详解

GCC 编译命令的基本格式为：

gcc [选项] 源文件 -o 输出文件

常用编译选项：

选项含义示例
-o <file>指定输出文件名gcc hello.c -o hello
-Wall启用所有常见警告，帮助发现潜在问题gcc -Wall hello.c -o hello
-g生成调试信息，配合 GDB 等调试器使用gcc -g hello.c -o hello
-std=c99指定使用 C99 标准gcc -std=c99 hello.c -o hello
-std=c11指定使用 C11 标准gcc -std=c11 hello.c -o hello
-O2开启优化（O2 级别，平衡编译时间和运行效率）gcc -O2 hello.c -o hello

本教程推荐日常使用的编译命令：

$ gcc -Wall -g -std=c11 hello.c -o hello

这条命令会启用警告、生成调试信息、使用 C11 标准来编译你的程序。
